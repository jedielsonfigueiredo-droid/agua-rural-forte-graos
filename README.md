# Água Rural — Forte Grãos

Aplicativo para registro e acompanhamento de hidrômetros, horímetros e outorgas da Forte Grãos.

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` no navegador.

## Publicação

O projeto contém um arquivo `render.yaml` para criação do serviço no Render.

> Esta versão é o protótipo funcional da interface. A persistência compartilhada, autenticação de usuários e armazenamento definitivo das fotos devem ser ativados antes do uso operacional por vários usuários.
